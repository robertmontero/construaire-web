# Construaire del Caribe S.A.S. — web corporativa

Sitio estático (HTML, CSS y JavaScript, sin servidor) de Construaire del Caribe S.A.S.,
servicios de aire acondicionado y refrigeración en Santa Marta.

- `index.html` — página principal
- `politica-datos.html` — política de tratamiento de datos (Ley 1581 de 2012)
- `styles.css`, `app.js` — estilos y comportamiento (formulario a WhatsApp o correo)
- `img/` — logo, íconos y fotos de trabajos

Publicado con GitHub Pages desde la rama `main`.
Para actualizar: editar los archivos y subir los cambios a `main`.
